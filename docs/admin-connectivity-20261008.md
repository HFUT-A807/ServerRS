# 管理员端联通验证

验证日期：2026 年 10 月 8 日。

本机管理员端现由 Rust 后端直接托管，页面与 API 均使用
`http://127.0.0.1:8080`。此前也已验证 Vite 开发代理方式。
后端使用现有 SSH 配置连接 HP 的 MySQL，
本地数据库隧道端口为 13306，数据库为 `digital_companion`。

## 修复内容

- `.env.example` 与 Vite、后端默认端口统一为 8080。
- 侧栏以真实健康检查显示检测中、已连接、未连接，5 秒超时，每 30 秒检测一次。
- 移除 Fresh Context 知识审核的导航、概览数据请求与发布入口。原知识审核地址显示暂停说明。
- 风险审计缺少等级时显示未判定，避免将未完成或失败的审计显示为无风险。
- 修复音乐 LONGBLOB 读取：实体按字节读取，仓库转为 UTF-8 base64 文本，避免 MySQL 不支持的 TEXT 转换及转换后列名丢失。数据库结构和现有音乐数据未变更。

后端离线编译、SDK 构建、管理员端类型检查及生产构建通过。
