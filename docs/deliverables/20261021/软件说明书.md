# 人机共情交互抑郁防范与健康促进系统

## 软件说明书

软件标识：数字人系统 ServerRS　　软件版本：1.0

文档版本：2026 年 10 月整理版　　日期：2026 年 10 月 21 日

开发单位：合肥工业大学计算机与信息学院 A807 实验室

本系统以可交互数字人为用户入口，围绕支持性交流、心理健康自评和健康促进活动组织服务。用户输入文本后，服务端生成回复并合成音频，前端播放服务端返回的音频，驱动数字人的说话表现，并同步展示文字。用户还可完成量表自评、记录情绪日记、阅读心理知识和收听舒缓音乐。

本说明书面向普通用户、授权管理员和部署联调人员，按使用顺序说明进入条件、操作步骤、操作结果及异常处理。量表与风险结果用于筛查信息展示和人工复核，不作为临床诊断结论。

# 1 系统组成与使用条件

### 1.1 系统组成

系统由用户端数字人界面、服务端、管理后台和数据及模型服务组成。用户端负责数字人展示、输入、字幕、音频播放和活动交互；服务端负责身份认证、对话处理、记忆与知识检索、语音生成、自评保存和业务数据管理。管理后台用于用户、风险会话、心理内容和音乐资源管理。

| 组成 | 作用 | 使用条件 |
| --- | --- | --- |
| 用户端数字人 | 展示数字人并播放回复音频 | 获取项目用户端地址或安装包 |
| Rust 服务端 | 提供 HTTP 业务接口 | 数据库及所需模型服务可用 |
| Vue 3 管理后台 | 提供管理员图形入口 | ADMIN 或 SUPER_ADMIN 账号 |
| MySQL | 保存账号 对话 自评 日记等数据 | 数据库连接与结构正确 |
| 向量与模型服务 | 支持回复生成 语义检索和语音 | 按实际部署启用并完成配置 |

### 1.2 账号与权限

普通用户登录后使用本人对话、自评、日记和活动建议。部分知识、音乐及社区内容提供公开读取接口，用户端是否允许匿名浏览由页面入口决定。管理接口同时检查有效登录身份和管理员角色。

### 1.3 终端与网络

用户按交付的用户端要求使用 Windows 或 Android 终端；浏览器访问时应允许音频播放，并保证服务地址可达。本文不限定数字人渲染引擎或模型资产格式。管理后台采用浏览器访问。离线部署方案为 x86-64 Windows 主机上的 Linux 容器。

本地模型可支持离线文本交流；语音服务、天气和外部网页等能力仍受各自网络及配置条件约束。不能仅凭文本聊天可用认定语音和外部工具全部可用。

### 1.4 功能状态

现有服务端具备文本对话、对话语音、待审批恢复、自评、日记、资源和管理接口。语音输出需要启用 TTS 并完成服务配置。Fresh Context 当前暂停；管理后台的知识审核入口显示暂停说明。旧风险手工处置接口已停用。数字人的具体外观和控制位置以项目用户端为准。

# 2 登录与快速开始

### 2.1 进入系统

由部署人员提供用户端地址或安装包、服务地址和账号获取方式。管理后台地址与用户端地址可能不同。首次使用前检查终端音量及网络，并准备可用账号。不要将管理后台地址当作数字人用户端入口。

### 2.2 注册与登录

在用户端登录入口输入用户名和密码并提交。提供注册入口的版本可先填写注册信息；字段要求以页面和接口校验结果为准。登录成功后进入主界面，系统使用访问凭证识别用户。登录失败时核对输入和账号状态；提示身份失效时重新登录。

退出或切换账号后，应停止当前音频、关闭本人活动提醒并清空页面中的个人数据。不要在公共终端保留密码或访问凭证。

### 2.3 完成第一次数字人交流

1. 进入数字人交流区域，确认数字人已加载，输入一段简短文本。
2. 点击发送，等待服务端处理，避免重复点击同一条消息。
3. 文字和音频返回后，阅读字幕并收听数字人回复。浏览器阻止自动播放时，点击播放控件。
4. 声音播放结束后继续输入，形成多轮交流。只返回文字时先使用文字交流，并检查语音状态。

### 2.4 完成一次自评与活动反馈

进入心理自评，选择量表、阅读说明并完整作答。提交后查看得分、筛查等级、记录时间和活动建议。可选择呼吸练习或情绪日记；实际完成后提交“完成”，也可选择“忽略”或“稍后提醒”。

| 场景 | 用户应看到的结果 | 下一步 |
| --- | --- | --- |
| 登录成功 | 进入本人界面 | 开展交流或自评 |
| 对话完成 | 回复文字及可用音频 | 阅读 收听或继续交流 |
| 工具等待审批 | 待确认事项与操作说明 | 自主批准或拒绝 |
| 自评提交成功 | 已保存记录与两类建议 | 查看或选择活动 |
| 网络中断或超时 | 失败提示或连接异常 | 先查询记录再决定是否重试 |

# 3 数字人交流与音频驱动

### 3.1 交流流程

用户输入文本，可附带情绪标签。服务端结合本轮输入、允许使用的用户资料、对话上下文、记忆或知识生成支持性回复；语音模式下将回复合成为音频，返回文字与音频地址。前端获取音频并驱动数字人展示说话过程。

![数字人交流流程](assets/manual_audio_flow.png)

数字人的声音来源是服务端返回的音频。口型计算和渲染发生在前端或其数字人驱动组件中；当前接口不返回音素时间轴、面部骨骼参数或视频流。情绪标签为输入上下文，不等同于系统已完成面部或声纹情绪识别。

### 3.2 正常使用与异常处理

播放时可按用户端提供的控制暂停或停止；新一轮播放应避免与上一轮声音重叠。音频无法播放时，已收到的文字应继续保留。音频地址短时有效，不适合作为历史音频永久保存或分享。

如果语音请求本身失败，前端可能尚未收到文字，但服务端已完成本轮对话保存。此时先查询历史，确认是否已有回复，避免自动重发而生成重复轮次。不能将“重新生成”当作已有独立重试音频接口。

### 3.3 待审批交流

当受控工具需要确认时，系统返回待审批状态，本轮不生成音频。用户查看待执行事项后选择批准或拒绝。刷新页面后可重新查询待审批列表；查询不会执行工具。恢复后可能继续产生待审批事项，当前恢复接口只返回文字。

### 3.4 交流边界

系统提供支持性回应和健康信息。风险审计在对话轮次结束后异步执行；尚未出现审计结果不表示已确认无风险。不要将数字人说话表现理解为已实现自动人工接管、紧急通知或医疗处置。

# 4 个人资料与交流数据管理

### 4.1 个人资料与个性化交流

在个人资料入口查看或修改部署版本支持的资料及偏好，保存后重新读取确认。服务端可将已保存的资料、画像摘要、记忆和历史摘要用于后续交流；具体效果还受模型、配置与已存在数据影响。

建议在更改偏好后使用新的交流轮次核对结果，不把旧回复变化作为保存成功的依据。个性化内容应由用户自行提供或确认，不能将模型推断当作用户已经明确表达的事实。

### 4.2 查看历史与记忆

进入对话历史，按时间回顾本人消息；较早记录通过继续加载获取。进入记忆或画像入口可查看当前可用数据。页面是否提供所有高级管理入口由用户端版本决定，服务端保留对应接口。

| 操作 | 主要作用 | 使用提醒 |
| --- | --- | --- |
| 查询历史 | 回顾本人对话文本 | 不能据此保证历史音频仍可播放 |
| 查询记忆 | 查看用于交流的记忆 | 以当前返回记录为准 |
| 禁用单条记忆 | 停用指定记忆 | 之后重新查询核对状态 |
| 重置画像 | 重置系统画像 | 不等于删除账号或全部记录 |
| 重建画像 | 重新形成画像结果 | 受历史数据和模型状态影响 |
| 清空对话文本与摘要 | 清理对应交流资料 | 执行前阅读当前版本提示 |
| 忘记上下文 | 清理相关记忆 摘要及画像 | 不等同于全库数据删除 |

### 4.3 删除与退出

删除记录前核对对象。删除自评、日记、社区内容和注销账号属于不同操作，不能相互替代。清空交流上下文也不代表自动删除自评、日记、审计或备份。

退出登录后前端应清理个人数据缓存及播放器。对访问凭证、个人资料、音频签名地址和聊天内容采用受控保管方式；向维护人员反馈问题时提供时间和错误提示即可，避免附上密码或完整令牌。

### 4.4 跨用户隔离

个人记录按服务端认证身份查询，不依赖前端随意指定用户编号。访问其他用户资源时接口应拒绝，可能返回 403 或 404。管理员身份并不意味着普通用户端可以任意切换他人身份。

# 5 心理健康量表自评

### 5.1 选择量表

在自评入口获取当前量表列表，进入详情查看说明、题目和选项。现有种子数据及最近一次量表核验记录对应下列配置；实际使用始终以当前接口返回为准。

| 量表 | 题数 | 原始分范围 | 展示注意事项 |
| --- | --- | --- | --- |
| PHQ-9 | 9 | 0 至 27 | 按配置区间展示筛查等级 |
| SDS | 20 | 20 至 80 | 区分原始分与标准分说明 |
| CES-D | 20 | 0 至 60 | 使用现有题目与选项分值 |

当前配置包含 CES-D，不把 BDI-II 列为已经提供的量表。SDS 标准分展示按系统说明采用原始分乘 1.25 后四舍五入；提交的选项分值应取自详情，不由前端自行反转题目或改变计分。

### 5.2 作答与提交

1. 阅读量表说明，按题目选择符合自身情况的选项。
2. 检查所有题目已作答，使用实际量表编号及题号提交。
3. 服务端校验答案并计分；提交成功后展示评估编号、原始总分、筛查等级和保存时间。
4. 同时展示本次评估关联的呼吸练习与情绪日记建议。

题目缺失、题号错误、分值不合法或请求格式错误时，应提示修正并保留已填写答案。请求超时时先查询自评列表，核对提交时间和内容，再判断是否补交。再次提交会产生独立记录及建议。

### 5.3 查看和删除记录

在自评记录列表打开详情，核对本人答案、分数、等级及关联活动。需要删除时确认对应评估编号，删除后刷新列表。与评估关联的建议可能随评估删除而移除。

### 5.4 结果理解

自评得分反映本次回答按系统配置计算的结果；筛查等级与对话风险审计是两类不同信息。当前活动建议不随量表分数变化，也不由后台风险审计触发。页面不能将筛查等级、模型置信度或数字人回复展示为确诊结论。

# 6 健康促进建议与情绪日记

### 6.1 获取建议

每次成功保存新自评时，服务端在同一数据库事务中保存呼吸练习和情绪日记两条建议，并随响应返回。查看自评详情也可读取关联建议。历史评估不会自动补发建议，查询操作不会新建建议。

用户登录且页面处于前台时，用户端按服务端给出的间隔查询到期的待处理建议，默认不少于 20 秒。页面隐藏时暂停查询，重新可见后刷新。关闭应用后没有后台系统推送。

### 6.2 选择活动与反馈

| 用户选择 | 提交状态 | 后续表现 |
| --- | --- | --- |
| 完成活动 | completed | 从待处理列表移除 |
| 忽略建议 | dismissed | 从待处理列表移除 |
| 稍后提醒 | pending 加 remindAt | 延期隐藏 到期后重新查询显示 |

延期时间使用带时区时间，必须晚于服务端当前时间且不超过未来 7 天。完成和忽略为终态，不能重新打开；重复相同终态可成功，冲突状态返回 409。

呼吸动画、计时和引导语由前端呈现。进入活动页或播放引导不等于活动已完成，应在用户完成并确认后更新建议状态。服务端不自动判断用户是否完成呼吸练习。

### 6.3 情绪日记

进入日记列表，选择新增，填写正文，可填写标题，保存后在列表核对。正文长度为 1 至 10000 字符。打开详情后可修改内容，也可确认删除本人日记。

从情绪日记建议进入时，先保存日记，再将对应建议标记完成。日记保存与建议更新是两个请求：日记已保存而建议更新失败时，只重试建议更新，避免重复创建日记。日记接口本身不会自动完成建议。

### 6.4 连接与账号变化

查询失败不应被显示为“没有建议”。保留最后一次成功数据并提示连接问题；恢复后替换为最新列表，避免重复追加卡片。退出、切换账号及身份失效时停止轮询并清理当前用户卡片。

# 7 心理知识 音乐 社区与文件

### 7.1 心理健康知识

进入心理知识区域，选择分类并浏览文章、问答或自助资源。打开条目查看标题、正文、来源或关联资源；部分资源会跳转外部地址。用户登录后可使用接口支持的收藏、收藏状态查询及点赞功能，具体控件以用户端为准。

知识文章和自动网页摄入是不同入口。当前管理后台知识审核页面暂停，不影响通过心理内容管理维护文章、问答、分类与资源。不能将暂停页面理解为现有文章全部不可阅读。

### 7.2 舒缓音乐

浏览曲库，可按当前页面提供的分类或搜索条件筛选。选择曲目后核对名称、作者和时长，点击播放。服务端播放接口返回音频数据，前端按媒体类型交给播放器。

音乐与数字人语音宜分开控制音量，并避免同时高音量播放。浏览器拦截播放时等待用户主动点击。音频拖动定位、后台播放等能力取决于实际播放器和接口支持，不能仅凭有音频地址认定全部具备。

### 7.3 社区互动

用户端提供社区入口时，可浏览帖子与评论；登录后按权限发表、修改或删除本人帖子，参与评论和点赞。提交后刷新或读取详情核对。没有发布成功提示时先查询，避免重复发帖。

社区内容为用户发布信息，与系统知识文章及个人日记分开管理。删除帖子、删除日记、清空聊天上下文为不同业务操作。

### 7.4 文件资源

需要上传文件的功能通过对象接口处理。上传成功后保存返回的对象编号；查看或删除对象时使用实际编号并接受权限校验。对象编号不等同于永久公开下载链接，外部资源地址也不等同于系统对象。

| 资源 | 获取方式 | 异常时检查 |
| --- | --- | --- |
| 心理文章与问答 | 列表进入详情 | 是否发布 分类与编号是否正确 |
| 音乐 | 曲目详情和播放接口 | 媒体类型 文件与网络状态 |
| 社区 | 帖子和评论列表 | 登录权限 对象归属与实际状态 |
| 文件对象 | 上传后按编号访问 | 大小 格式 权限与存储空间 |

# 8 管理后台操作

### 8.1 登录后台

使用部署方提供的管理地址，以 ADMIN 或 SUPER_ADMIN 账号登录。离线部署包通常使用 http://localhost:3000/；由后端直接托管时通常使用 http://127.0.0.1:8080/。不同部署地址不可混用。

登录后进入运行概览，通过侧栏进入用户管理、风险会话、心理内容和音乐资源。知识审核旧入口当前显示暂停说明。后台连接状态仅表示 HTTP 可达，不代表数据库、模型、语音和所有业务均正常。

### 8.2 用户与内容管理

用户管理用于查看账号并按权限调整状态、角色或删除用户。操作前核对用户编号与用户名，保存后重新查询。心理内容管理用于维护分类、文章、问答和资源；音乐资源管理用于维护曲目信息及关联音频。

### 8.3 风险会话与审计记录

在风险会话列表按可用条件筛选并分页，打开详情核对会话、消息与 risk_audits。通过消息引用识别具体交流轮次。风险等级可包含 none、low、medium、high、crisis 或 unknown；等级为空时应展示未判定。

| 审计状态 | 含义 | 管理员处理方式 |
| --- | --- | --- |
| pending | 已建立任务 等待执行 | 稍后刷新 |
| running | 正在审计 | 等待结果 不提前判定 |
| completed | 审计成功得到结果 | 结合关联消息人工复核 |
| failed | 审计失败 | 查看错误并交维护人员排查 |

模型置信度不是患病概率。created_at 为记录创建时间，不能标注为准确审计完成时间。审计失败不等于无风险。当前后台支持风险信息查询；旧“标记已处理”接口返回 410，不提供该操作，也不承诺邮件告警或自动干预。

### 8.4 管理操作注意事项

管理员按授权范围访问敏感信息。不要向普通用户暴露管理页面数据或下载完整审计记录用于无关用途。删除、角色调整和内容更新后都应读取最新状态确认，不能只依据按钮点击成功判断业务完成。

# 9 部署与运行维护

### 9.1 离线容器部署

目标主机为 x86-64 Windows，已安装并启动 Docker Desktop，使用 Linux 容器模式。部署资料建议分配至少 16 GB 内存，24 GB 更合适；实际模型速度取决于硬件，纯 CPU 运行大型模型可能较慢。磁盘应同时容纳部署包、镜像、模型及持续增长的运行数据。

1. 复制并完整解压部署包，在部署目录打开 PowerShell。
2. 运行 Start-Offline.ps1，等待镜像导入和服务检查。
3. 首次启动安全保存脚本生成的管理员账号密码。
4. 打开管理页面，核对登录、健康检查和业务数据。
5. 使用 Stop-Offline.ps1 停止服务；后续启动继续使用原有数据。

停止不应删除数据。保留 .env、models 和 Docker 数据卷。init.sql 含数据库重建语句，只用于新环境，不能用于已有数据库升级。现有数据库先备份、核对结构，再选择缺失的增量迁移，不重复执行全部历史脚本。

### 9.2 数字人语音部署条件

启用 tts.enabled，配置可用语音服务、资源标识、访问密钥、URL 签名密钥及 ffmpeg。签名密钥按配置要求至少 32 字符。public_url_base 必须是用户终端可访问的地址；远程终端不能使用服务主机的 127.0.0.1 地址下载音频。

浏览器通过 HTTPS 访问时，应使音频地址也可通过 HTTPS 访问，避免混合内容阻断。allowed_voices 为空时只使用默认音色，前端宜省略 voice。音频有效期和文件清理周期由部署配置控制。离线包包含本地对话模型，不代表已经包含可离线运行的语音引擎。

### 9.3 运行检查与备份

| 检查项 | 建议操作 | 判断方式 |
| --- | --- | --- |
| 服务可达 | 请求 /health | 结合业务接口进一步检查 |
| 对话与音频 | 使用专用测试账号交流 | 文字 音频下载和数字人表现正常 |
| 数据与文件 | 备份 MySQL 对象及必要配置 | 在隔离环境验证恢复 |
| 日志与空间 | 查看错误 日志增长和磁盘 | 保留必要信息并保护敏感内容 |

# 10 常见问题与接口索引

### 10.1 常见问题

| 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 有文字无声音 | 纯文本模式 TTS 未启用或播放被阻止 | 检查模式 配置与播放权限 |
| 有声音但数字人不动 | 前端驱动组件或音频绑定异常 | 检查音频输入与渲染状态 |
| 音频无法加载 | 链接过期 地址不可达或文件已清理 | 核对地址及响应 不自动重发对话 |
| 操作一直等待 | 模型或网络耗时 | 保留输入 查询历史确认结果 |
| 建议未出现 | 历史评估 延期或已处理 | 查看本次评估详情及建议状态 |
| 风险暂无结果 | 后置审计未完成或失败 | 按审计状态判断并刷新 |
| 401 或 403 | 身份失效或权限不足 | 重新登录或联系账号管理员 |
| 409 或 410 | 状态冲突或旧接口停用 | 查询新状态或停止旧调用 |

### 10.2 主要接口

下列路径均相对于服务根地址。个人及管理接口携带有效 Bearer 凭证；音频下载使用响应中完整的签名 URL，不自行拼接。

| 功能 | 方法与路径 |
| --- | --- |
| 登录 | POST /api/v1/auth/login |
| 文本对话 | POST /api/v1/chat/messages |
| 对话与音频 | POST /api/v1/chat/messages-with-audio |
| 对话历史 | GET /api/v1/chat/history |
| 待审批列表 | GET /api/v1/chat/checkpoints/pending |
| 恢复待审批 | POST /api/v1/chat/checkpoints/{id}/resume |
| 量表与自评 | GET /api/v1/depression/scales；POST /api/v1/depression/assessments |
| 建议与日记 | GET /api/v1/wellbeing/recommendations；GET /api/v1/diaries |
| 风险详情 | GET /api/v1/admin/risk-conversations/{id} |
